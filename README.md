# Spending Coach

Agent #2 of my agent series. It doesn't just total your spending. It finds what changed, why, and what to do.

**Simple output:** spending by category.
**Agent output:** "October spending is up $216, almost all food delivery: 12 orders vs. 4 in September ($324 vs. $103). Also: your streaming plan went up $2.50 and cloud storage was charged twice."

## The idea: give the model tools, not the spreadsheet

The model never sees the CSV. It calls exact tools and reasons over their results:

| Tool | Returns |
| --- | --- |
| list_months | income, spent and net per month |
| spend_by_category | totals per category for a month |
| compare_months | change per category between two months, in $ and % |
| find_transactions | matching transactions, count and total |
| top_merchants | where the most money went in a month |
| recurring_charges | subscriptions, price increases, duplicate charges |

```
question -> agent (Claude) --needs data?--> tools (exact Python) --> agent --> ... --> answer
```

Built with LangGraph: an agent node, a tool node, and a loop between them (capped at 12 steps).

## Run it (Windows PowerShell)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env      # then put your ANTHROPIC_API_KEY in .env
pytest -q                   # 7 tests, no API key needed
streamlit run app.py        # the demo
python compare.py           # tools vs. pasting the CSV: accuracy and tokens on 10 questions
```

`sample_data/transactions.csv` is made up (generated by `scripts/make_sample.py`). You can upload your own bank CSV in the app; it stays on your computer except for the tool results sent to the model.
